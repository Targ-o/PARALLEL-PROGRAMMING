
## Задание
Модифицировать программу из лабораторной работы №1 для параллельной работы по технологии **OpenMP**. Провести серию экспериментов с разным количеством потоков (1, 2, 4, 8) и разными размерами матриц (от 20х20 до 2000х2000). Реализовать автоматизированную верификацию результатов вычислений.

## Описание алгоритма и параллелизации
Для оптимизации работы с кэш-памятью классический алгоритм умножения матриц \(O(N^3)\) изменен на схему **i-k-j**:
1. Внешний цикл i итерируется по строкам матрицы \(A\).
2. Промежуточный цикл k обходит элементы текущей строки.
3. Внутренний цикл j последовательно накапливает значения в результирующей матрице \(C\).

Параллелизация реализована с помощью директивы #pragma omp parallel for num_threads(threads) перед внешним циклом i
