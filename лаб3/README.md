## Задание
Модифицировать программу из л/р №1 для параллельной работы по технологии MPI. Провести серию экспериментов с разными размерами матриц (примерно 200, 400, 800, 1200, 1600, 2000), с разным количеством вычислительных ядер (1, 2, 4, 8 и т.д.).
Параллельную версию программы на MPI необходимо запустить на суперкомпьютере «Сергей Королёв».


### Описание алгоритма и параллелизации

Для умножения квадратных матриц A и B размером N × N используетсяиалгоритм с вычислительной сложностью O(N³). Элементы результирующей матрицы вычисляются по формуле:
C[i][j] = sum(A[i][k] * B[k][j]), k = 0 ... N-1
В программе используются три вложенных цикла: внешний цикл проходит по строкам матрицы A, средний — по столбцам матрицы B, внутренний — суммирует произведения соответствующих элементов.

Для каждой конфигурации измерялось время вычислений (`Computation time`) и общее время параллельной части программы с передачей и сбором данных (`Total time`). В таблицах ниже используется именно `Total time`

Коэффициент ускорения рассчитывался по формуле:
S(p) = T(1) / T(p)
где `T(1)` — общее время при одном MPI-процессе, а `T(p)` — время при p процессах

Эффективность параллелизации рассчитывалась по формуле:
E(p) = S(p) / p × 100%

Измерения приведены для одного запуска каждой конфигурации. Для более надёжных выводов рекомендуется повторить каждый эксперимент не менее 3–5 раз и сравнивать медианное время.
